## 🚀 Featured Projects

### 🧠 JARVIS OS — AI-Powered Desktop Dashboard
A full-stack, Iron Man-inspired command center combining a Node.js/Express backend with a feature-rich
interactive frontend.
- Real-time system diagnostics and a live floating terminal
- Voice recognition for hands-free control
- Claude AI integration for conversational assistance
- Calendar, live weather data, and animated particle UI
- Multiple personality/theme modes, evolved across several iterations
- **Stack:** Node.js, Express.js, JavaScript, Web Speech API

### 🚑 AutoResQ — Intelligent Accident Detection Platform
A full-stack emergency-response system that detects vehicle accidents and automatically notifies
emergency services in real time.
- Backend REST APIs built with Node.js and Express.js
- PostgreSQL + Supabase for accident and user data storage
- JWT-based authentication for secure, multi-user access
- Automated, event-driven emergency alert workflows
- **Stack:** Node.js, Express.js, PostgreSQL, Supabase, JWT

### 🤖 AI Virtual Assistant — System Automation Assistant
An AI-powered assistant for managing everyday computer tasks through natural, command-based automation.
- Modular, event-driven architecture for extensibility
- LLM-backed command interpretation and task execution
- Built-in command validation for safe automation
- **Stack:** Node.js, TypeScript, LLM Integration
